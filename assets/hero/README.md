# Hero muted loop

Drop any of these files here to replace the CSS terminal animation on the home hero:

| File | Notes |
|------|--------|
| `loop.mp4` | Preferred (H.264, short, no audio) |
| `loop.webm` | Optional fallback |
| `loop.gif` | Works; keep under ~2–3 MB |

Priority: mp4 → webm → gif → built-in scrolling terminal.

Tips: 10–20s loop, muted, screen recording of Playwright / Pact / k6 / CI. Keep face-cam and audio out.
