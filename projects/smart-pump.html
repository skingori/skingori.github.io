Case study

Smart Pump Controller

Smart pump control end to end — mobile app, Django API, firmware, Kong gateway, and infrastructure — with unit tests, Pact contracts, Appium and Maestro mobile automation, a custom Kong auth plugin, Terraform-managed environments, and CI/CD.

Django REST Expo / React Native Firmware Kong Pact Appium Maestro Terraform Minikube / K8s

The problem

A water pump that only works on-site is slow to operate and hard to trust. Operators need remote start/stop, schedules, and device status — without breaking when the API, app, or firmware drift apart, and without paying a full auth round-trip on every call.

The approach

Build it as a monorepo production system: Kong in front of the API, clear service contracts, infrastructure as code, and a test strategy that catches integration breaks before release — not only happy-path UI checks.

Kong gateway & auth plugin

Auth once — not on every call

A custom Kong auth plugin checks credentials against the database so subsequent API calls reuse a validated session instead of forcing a full login on every request — lower latency on the hot path for mobile and firmware traffic.

Faster API path

Custom Kong auth plugin avoids re-login on every request by validating against the DB session — built for chatty mobile and device traffic without sacrificing control at the gateway.
